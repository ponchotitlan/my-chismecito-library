## Abstract
- **Version:** final

Building multi-agent AI systems today looks a lot like the Tower of Babel: too many frameworks, too many protocols, and very little understanding between them. The result? Teams spend more time wiring things together than building anything new.

AGNTCY is an open-source project under the Linux Foundation that aims to fix this by giving agents a shared vocabulary and stack for the four things they need to work together: Discovery, so they can find each other; Composition, so they can communicate and truly understand each other; Deployment, so they can run safely and responsibly in the wild; and Evaluation, so you know what is actually happening across your distributed system. The goal is a common framework and reference that works with the agent frameworks of today, and with whatever ships next week.

In this session, we'll open the hood and build a real multi-agent, multi-framework system live, using every AGNTCY component along the way. You'll watch agents built with different frameworks discover, talk to, and evaluate one another.

You'll leave with a solid understanding of open-source agent interoperability and a clear sense of whether AGNTCY belongs in your stack today or down the road. Basic familiarity with AI agent concepts is recommended. The demo code will be available in a public repository, so you can follow along or try it afterward.
